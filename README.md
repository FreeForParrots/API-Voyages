# API-Voyages

# Choix technologique - FastAPI
## 1. Simplicité et rapidité de développement

FastAPI a été choisi pour sa simplicité et sa rapidité de développement. Grâce à la syntaxe claire de Python, il permet de créer des endpoints et de gérer les requêtes HTTP avec moins de code et une configuration moins complexe que Symfony.

Ce choix facilite également la maintenance du projet et permet d'ajouter de nouvelles fonctionnalités plus rapidement.

## 2. Documentation automatique de l'API

Un autre avantage important de FastAPI est la génération automatique de la documentation de l'API grâce à Swagger UI et ReDoc.

Cette fonctionnalité permet de consulter les différents endpoints, de visualiser les paramètres attendus et de tester directement les requêtes depuis une interface interactive.

Contrairement à Symfony, qui nécessite généralement l'ajout d'une extension comme NelmioApiDocBundle pour obtenir une documentation similaire, FastAPI intègre cette fonctionnalité nativement. Cela simplifie le développement et facilite les phases de test et de maintenance.

## 3. Validation automatique des données

FastAPI utilise Pydantic pour assurer la validation des données reçues par l'API.

Ce mécanisme permet de définir précisément les types et les formats des données attendues, de détecter automatiquement les erreurs et de retourner des réponses HTTP adaptées.

Ce choix permet de réduire la quantité de code nécessaire à la validation, de limiter les erreurs liées aux données incorrectes et de renforcer la fiabilité des échanges entre le client et le serveur.

## 4. Intégration avec l'écosystème Python

Le choix de FastAPI permet également de profiter de l'ensemble de l'écosystème Python et de ses nombreuses bibliothèques.

Cela offre davantage de possibilités pour faire évoluer le projet, notamment en intégrant des outils de traitement et d'analyse de données, des solutions d'automatisation ou encore des fonctionnalités d'intelligence artificielle.

Cette flexibilité représente un avantage pour les évolutions futures du projet, sans nécessiter de changement de langage ou de framework.
